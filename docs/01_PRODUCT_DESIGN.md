# 01. 제품과 디자인 명세

## 2026-10-30 필름 전역 색조 제거

필름 0.6은 셀로판 같은 인상이라는 피드백에 따라 전역 녹색/주황 tint를 제거한다. 깊은 명암·완만한 밝은 계조·선택적 색상 조정과 입자로 구성하며 softness는 8%다. 날짜 기본 켜짐과 디카0.3은 유지한다. 아래 과거 수치보다 우선하며 최종 색감은 사용자 확인 대기다.

## 2026-10-30 필름 질감·날짜 후속 개정 (이전)

디카는 사용자에게 원하는 느낌에 가까워졌다는 피드백을 받았고 수치를 유지한다. 필름은 미승인으로 녹회색 검정·입자 크기/진폭·소프트 포커스를 조정했다. 필름 선택/초기화 시 오늘 날짜 도장을 기본으로 켜고 오른쪽 아래 주황색 YY.MM.DD로 표시한다. 질감 패널에서 끌 수 있으며 결과 재편집/저장에는 촬영 날짜를 유지한다. 필름 look 0.5, 디카 0.3이며 최종 필름 색감은 확인 대기다.

## 2026-10-30 실제 레퍼런스 우선 개정 (이전)

직접 첨부한 필름 사진과 Instagram 세 번째 이미지의 SE BLUR 예시를 기준으로 이전 고채도/직광 디카 목표를 대체한다. 이름은 **플래시 필름**, **소프트 디카**. 필름은 녹회색 그림자·살구빛·입자, 디카는 저채도·뽀얀 흰빛·부드러운 윤곽이다. 공통 질감 패널의 ‘소프트 포커스’를 미리보기/결과 재편집 모두에서 조절한다. 필름 22%, 디카 72%, 나머지 0% 기본값. 자세한 수치와 관찰 한계는 [색감 방향](RETRO_LOOK_DIRECTION.md)을 따르며 최종 색감 승인은 대기다.


## 2026-10-30 필름·디카 색감 재조정

사용자가 필름은 ‘일회용 카메라처럼 거친 입자와 진한 색’, 디카는 ‘2000년대 싸이월드·직광 플래시 스냅’을 선택했다. 필름은 **일회용 필름 / 0.3.0-draft**로 바꾸고 명암·채도·입자 강도를 높였다. 디카 2005는 0.2.0-draft의 깊은 명암·차가운 흰빛을 유지한다. 두 카메라 조절 패널에 실제 플래시 켜기/끄기를 제공하고 미지원 시 안내한다. 필터 선택만으로 플래시를 켜지 않는다. 기본 강도 90%, 날짜·먼지·빛샘 꺼짐. 조사 근거·수치·한계는 [색감 방향 기록](RETRO_LOOK_DIRECTION.md)을 따르며 최종 색감 승인은 대기다.

## 2026-10-30 저장 전 색감 재편집

결과 화면의 ‘저장 전 색감 바꾸기’에서 현재 적용된 설정을 시작점으로 필터·강도·질감·날짜 도장을 조절한다. 설정을 고르는 동안 사진은 마지막으로 적용한 결과를 표시하며, ‘선택한 색감 적용’을 눌러야 새 사진을 만든다. 적용 성공 또는 취소 시 사진 위치로 돌아간다. 조절값 변경마다 고해상도 렌더를 반복하지 않는다.

- 적용 성공 후에는 결과 제목·비교·저장이 새 설정과 사진을 따른다. 취소는 적용 전 선택만 버리고 마지막 결과를 유지한다.
- 실패/처리 중 앱 중단 시 이전 결과를 보존하고 다시 적용할 수 있다. 편집 중 저장/사진 버리기와 원본 비교는 잠그며, 적용 중에는 편집 취소도 잠근다.
- 다음 촬영의 카메라 설정은 바꾸지 않는다. 촬영 날짜·구도·입자 seed도 유지한다. 새 날짜 도장을 켜더라도 촬영한 날을 표시한다.
- 이미 갤러리에 저장한 결과는 이번 편집 대상에서 제외한다. 실행 검증은 NOT_RUN이며 아래 원본 비교 설명의 ‘촬영 당시 필터’는 편집 성공 이후에는 마지막 적용된 필터로 대체된다.

## 2026-10-30 촬영 결과 원본 비교

촬영 결과 화면에서 ‘촬영 원본과 비교하기’를 누르면 같은 사진의 방향과 중앙 crop을 맞춘 비교 이미지를 준비한다. 준비 후 누르는 동안 원본을 보거나 ‘원본 유지’ 스위치로 고정할 수 있다. 프레임 크기는 전환 중 유지하고 원본/필터 결과 배지를 표시한다. 원본 또는 강도 0으로 촬영했다면 비교 조작은 숨긴다.

비교는 표시 전용이며 필터 선택·강도·질감·촬영 날짜를 바꾸지 않는다. 저장 버튼은 항상 촬영 당시 필터가 적용된 고해상도 결과를 저장한다. 원본 보기는 전체 효과와 날짜 도장이 없는 JPEG이며 방향/crop 정규화와 화면용 축소를 거치므로 원본 파일 바이트나 1:1 픽셀 검수용 표현은 아니다. 저장 전 재편집은 다음 범위다. 코드 작성 상태이며 실행 검증은 NOT_RUN이다.

## 2026-10-29 승인된 필름·디카·도시 색감 확장

사용자는 기존 결과 원본 비교 개발보다 먼저 필름 35, 디카 2005, 로즈 데이, 맑은 여행 4종과 날짜 도장·빛샘·먼지 선택 효과 추가를 승인했다. 기존 계획 9종에 4종을 더해 제작 목표는 13종이다. 현재 앱에는 기존 대표 3종과 새 4종, 총 7종과 원본을 노출하며 기존 미제작 6종은 아직 선택할 수 없다. 색감은 모두 초안이며 사람의 최종 색감 승인을 뜻하지 않는다.

- 필름 35: 따뜻한 필름색, 입자, 비네팅과 붉은 빛 번짐.
- 디카 2005: 대비와 색을 살린 소형 디카 분위기, 윤곽 선명도와 디지털 컬러 노이즈. 실제 CCD나 특정 카메라 모델의 정밀 재현은 아니다. 플래시는 기존 촬영 설정에서 별도 선택하며 자동으로 켜지 않는다.
- 로즈 데이: 분홍 하이라이트와 청록 계열을 살린 자체 색감.
- 맑은 여행: 밝고 부드러운 명암, 맑은 하늘색과 은은한 온기.

카메라의 가로 탭은 원본/빛/시간/장면/필름/디카/도시다. 도시는 로즈 데이와 맑은 여행을 포함하고 필터 이름 또는 조절 버튼을 누르면 전체 색감 목록을 가로로 선택할 수 있다. 이미 활성인 컬렉션 탭을 다시 눌러도 현재 조절값을 초기화하지 않는다. 초기화는 전용 버튼으로 한다.

상세 패널의 ‘질감과 레트로 효과’를 펼쳐 입자·번짐·가장자리 어둡게·붉은 번짐·윤곽 선명도·디지털 노이즈·빛샘·먼지와 날짜 스위치를 조절한다. 날짜/빛샘/먼지는 모든 프리셋에서 기본 꺼짐이다. 날짜는 촬영 당시 기기의 현지 날짜를 YY.MM.DD로 오른쪽 아래에 합성하고 저장 결과에도 남긴다. 원본 비교와 강도 0은 날짜를 포함한 모든 효과를 우회한다. 세부 옵션은 기존 하단 패널 안에 있으며 카메라 영역 높이를 바꾸지 않는다.

**제품 상태:** 구현 전. 아래 숫자와 사용성 기준은 제품 가설이며 측정 결과가 아니다.  
**브랜드명:** 여운. 상표, 앱스토어, 도메인 사용 가능성을 확인하지 않은 가칭.  
**제품 코드명:** `yeoun-camera`.

## 1. 제품 정의

평범한 일상을 사용자가 느낀 분위기에 맞게 기록하는 실시간 카메라다. 필터 수를 늘리는 것보다 선택하기 쉬운 컬렉션, 촬영 결과에 대한 신뢰, 개인 설정의 재사용에 집중한다.

- 슬로건: **오늘의 빛을, 오래 남을 색으로.**
- 빛: 맑고 포근한 색. 흰색과 피부색을 과하게 누렇게 만들지 않는다.
- 시간: 바랜 명암과 입자. 먼지나 스크래치로 빈티지를 대신하지 않는다.
- 장면: 절제된 색과 명암. 무조건 어둡게 만들거나 검은 띠를 붙이지 않는다.

사용자는 로그인 없이 앱을 열고 컬렉션과 필터를 고른 뒤 촬영한다. 결과에서 원본과 비교하거나 같은 사진을 세 분위기로 살펴보고 갤러리에 저장한다. 마음에 든 조절값은 '오늘의 색'으로 남긴다.

## 4. 핵심 사용자 흐름

### F01. 첫 실행과 촬영

앱 설명 1장 -> '카메라 시작' -> 카메라 권한 -> 카메라 -> 필터 선택 -> 촬영 -> 결과 -> 저장.

권한 요청 전에 사용 목적을 설명한다. 앱 시작만으로 사진 앨범, 마이크, 위치 권한을 한꺼번에 요청하지 않는다. 카메라 권한을 거부한 사용자는 설정 이동이나 사진 가져오기를 선택할 수 있다.

### F02. 한 장, 세 분위기

결과 화면에서 사용자가 버튼을 누를 때 실행한다. 촬영은 한 번만 한다. 같은 원본, 같은 방향과 crop, 같은 렌더링 엔진 버전으로 세 대표 필터를 비교한다.

기본 비교는 각 대표 필터의 기본 강도 80%와 기본 입자와 번짐을 사용한다. 촬영 때 사용한 사용자 설정을 세 필터에 무조건 복사하지 않는다. 화면에 '각 컬렉션의 기본 설정'을 표시한다.

비교 썸네일은 긴 변 512px 이하로 한 장씩 생성한다. 사용자가 고른 결과만 고해상도로 export한다. 서로 다른 시점의 사진을 비교하거나 모든 결과를 갤러리에 자동 저장하지 않는다. 기존 선택으로 돌아오는 동작을 제공한다.

### F03. 오늘의 색

필터와 조절값을 선택 -> '오늘의 색으로 저장' -> 이름 입력 -> 로컬 DB 저장 -> '나의 색'에서 재사용.

이름은 앞뒤 공백 제거 후 1~24 Unicode code point로 제한한다. 중복 이름은 허용하되 내부 UUID로 구분한다. 레시피에 촬영 사진이나 위치를 저장하지 않는다. 필터 ID, 필터 버전, 엔진 버전, 필터 강도, 입자, 번짐을 저장한다. 촬영 노출값은 환경에 종속되므로 레시피에 복원하지 않는다.

레시피의 필터 버전이 없으면 최신 버전으로 몰래 대체하지 않는다. '이 설정에 필요한 필터 버전을 찾을 수 없어요'와 복구 안내를 표시한다.

### F04. 빛 가이드

선택지는 '전체 / 햇빛 / 흐린 날 / 실내 조명 / 밤'이다. 선택하면 추천 3개를 앞에 표시하되 전체 필터 목록은 그대로 이용할 수 있다. 실제 픽셀이나 카메라 white balance를 자동 변경하지 않는다.

| 환경 | 추천 순서 |
|---|---|
| 햇빛 | 오후 네 시, 여름방학, 엔딩 크레딧 |
| 흐린 날 | 우윳빛 아침, 봄의 공기, 비 온 뒤 |
| 실내 조명 | 우윳빛 아침, 오래된 일기, 엔딩 크레딧 |
| 밤 | 밤의 필름, 푸른 새벽, 비 온 뒤 |

이는 초기 추천 규칙이다. 추천 품질은 실제 사진으로 검수하며 AI 추천이라고 표현하지 않는다.

## 5. 화면 명세

### S01. 카메라

```text
┌──────────────────────────────────────┐
│ 플래시     빛 가이드          설정     │
│                                      │
│         3:4 촬영 프레임               │
│         초점 표시와 격자              │
│         노출 보정은 별도 조작         │
│                                      │
├──────────────────────────────────────┤
│ 빛 — 맑고 포근한 | 시간 | 장면        │
│ 원본 | 오후 네 시 | 우윳빛 아침 | ... │
│ 따뜻한 빛, 맑은 그림자        조절    │
│ 사진 가져오기     촬영       전후면   │
└──────────────────────────────────────┘
```

촬영 영역과 조작 영역을 분리한다. MVP는 UI를 세로로 유지하고 센서 방향을 반영해 가로 촬영 결과를 지원한다. 기본 촬영 비율은 4:3 센서 비율을 세로 표시한 3:4다. 안전 영역과 기기 화면 비율에 맞춰 여백을 허용하며 프리뷰를 화면 전체로 늘려 최종 구도를 숨기지 않는다.

카메라 출력이 정확한 4:3을 지원하지 않으면 지원 포맷을 선택하고 프리뷰와 저장에 같은 정규화 crop을 적용한다. 임의 확대나 왜곡은 금지한다.

필터 선택은 카메라 세션을 재생성하지 않는다. 슬라이더 값은 매 프레임 React state 갱신으로 전달하지 않는다. 필터 썸네일은 허가된 공통 기준 사진 또는 실제 엔진으로 만든 결과를 사용하고, 무관한 사진에 이름만 붙이지 않는다.

촬영 버튼은 준비 중, 카메라 전환 중, 기존 고해상도 저장 처리 중에는 비활성화한다. 플래시 미지원 기기에는 비활성 상태와 설명을 표시한다. 셀카 화면 플래시 기능은 MVP에 추가하지 않는다.

2026-10-28 격자·플래시 코드 작성: 카메라 프레임 위에 3×3 안내선을 기본으로 표시하고 상단 스위치로 끈다. 안내선은 저장 이미지에 합성하지 않는다. 플래시는 끔/자동/켬을 선택하며 기본은 끔이다. 실제 선택 기기의 `hasFlash`가 false이면 모드 버튼을 비활성화하고 미지원 안내를 표시한다. 카메라를 바꾸면 끔으로 초기화한다. 촬영·처리·저장 중에는 두 조작을 잠근다. 자동은 주변 밝기에 따라 발광을 결정하며 플래시 촬영은 미리보기와 밝기가 달라질 수 있음을 안내한다. 이번 설정은 세션 안에서만 유지하고 앱 재시작 후 설정 기억은 M3에서 구현한다. 실제 발광·화면·접근성 확인은 NOT_RUN이다.

### S02. 조절 패널

2026-10-29 촬영 보조 코드: 지원 기기에서는 프레임을 눌러 AF 초점을 요청하고 짧게 위치 표식을 보여준다. 스크린 리더 사용자는 '중앙 초점' 버튼을 사용할 수 있다. 초점은 continuous 모드와 5초 자동 복귀를 요청하며 초점 고정/AE·AWB 탭 측광 UI는 제공하지 않는다. 미지원 기기는 안내와 비활성 버튼을 표시한다. 초점 요청 성공은 실제 선명도 검증 완료를 의미하지 않는다.

촬영 노출은 필터 조절과 별도다. 지원 기기의 범위를 읽고 iOS는 0.5 EV 단위, 설치 Android 구현은 1 보정 단계 단위로 조절하며 경계에서 clamp한다. 표시값은 native 적용 후 읽은 값이다. '기본 밝기'는 0으로 복귀한다. 변경 중 촬영/중복 조절과 카메라 전환을 막으며 오류 때 다시 연결할 수 있다. 노출 적용 여부가 불확실하면 촬영을 막는다. 앱/결과/진단 복귀와 기기 재연결 시 기본 초점·밝기로 돌아간다. 원본 비교/필터 전환만으로 노출을 초기화하지 않는다. 실제 기기·접근성은 NOT_RUN이다.

필터 강도 0~100, 입자 0~100, 빛 번짐 0~100. 강도만 전체 스타일을 최종 혼합하며 입자와 번짐은 그 내부의 질감이다. 강도 0에서 입자와 번짐을 조절해도 원본은 유지되고, 안내 문구를 표시한다.

필터 전환 시 해당 필터의 기본값을 적용한다. 저장하지 않은 임시 조절값을 다른 필터에 암묵적으로 유지하지 않는다. '초기화'는 현재 필터의 기본값으로 돌아간다. 레시피를 선택하면 저장된 값을 복원한다.

원본 비교는 누르는 동안 원본을 보여주되, 접근성 사용자는 별도 토글로 같은 동작을 이용할 수 있다. 원본 비교는 촬영 설정을 변경하지 않는다.

2026-10-28 구현 범위는 카메라 미리보기다. '눌러서 원본 비교'는 손을 떼거나 제스처가 취소되면 복귀하고, '원본 유지' 스위치는 탭으로 켜고 끈다. 원본 모드/강도 0에서는 비교 조작을 숨긴다. 비교 중에는 촬영을 막고, 해제 후 선택한 색감의 새 draw가 준비되면 촬영을 허용한다. 필터/조절 변경, 전후면 전환, 앱 중단과 화면 이탈 시 비교를 해제한다. 촬영 설정과 고정 입자 seed는 비교 때문에 바뀌지 않는다. 결과 사진 비교는 아직 미구현이고, 카메라 비교도 실제 기기·접근성 확인 전이다.

### S03. 결과

큰 사진, 필터 이름, 원본 비교, 조절, 세 분위기 보기, 오늘의 색 저장, 갤러리에 저장, 공유, 카메라로 돌아가기를 제공한다.

저장은 자동이 아니다. 사용자의 저장 요청 이후 실행한다. 편집이 바뀌면 기존 export 파일을 재사용하지 않는다. 저장이 완료된 같은 설정에 다시 누르면 중복 저장 대신 '이미 저장했어요'를 표시한다. 실제 중복 방지와 프로세스 종료 한계는 기술 명세의 저장 상태 머신을 따른다.

미저장 상태에서 돌아가면 '아직 저장하지 않은 사진이에요'와 '계속 편집 / 버리기'를 표시한다. 실패 후에도 원본 초안을 유지해 재시도할 수 있게 한다.

### S04. 나의 색

즐겨찾기 필터와 개인 레시피를 구분한다. 레시피가 없으면 '마음에 드는 색감을 조절하고 저장해 보세요'를 표시한다. 이름 변경과 삭제는 접근 가능한 메뉴로 제공한다. 사용자 사진을 레시피 표지로 자동 보관하지 않는다.

### S05. 설정

격자 기본 켜기, 원본도 저장 기본 끄기, 셀카 미리보기와 같은 방향으로 저장 기본 켜기, 개인정보 안내, 오픈소스 정보, 임시 사진 지우기, 모든 로컬 설정 초기화를 제공한다. 마지막 두 동작은 삭제 범위를 안내하고 확인을 받는다. 기기 갤러리의 사진은 앱 초기화로 삭제하지 않는다.

## 6. 디자인 시스템

### Stitch 디자인 적용 — 2026-10-28

사용자가 지정한 [여운 Stitch 프로젝트](https://stitch.withgoogle.com/projects/7812018568704993424)의 카메라 기본, 필터 선택 트레이, 촬영 결과 화면을 기준으로 현재 구현 기능의 UI를 다듬었다. 전체 MVP 화면 완성이나 G0/G1 통과를 뜻하지 않는다. 적용 근거와 축소 범위는 [Stitch 적용 기록](STITCH_DESIGN.md)을 따른다.

실제 화면에는 차콜 배경, 작은 컬렉션 색 표시, 얇은 경계선, 3:4 프레임 모서리, 72px 원형 셔터, 필터 이름 중심 패널을 사용한다. 현재 컬렉션마다 대표 필터 한 개만 선택하며, 조절 패널을 펼쳐 강도·입자·빛 번짐을 조절하고 해당 필터의 기본값으로 초기화한다. 공간 효과는 후속 코드 작성 단계이며 실제 색감과 기기 동작은 검증 전이다. 결과는 별도 화면에 실제 JPEG와 저장 상태를 표시한다. 시안의 RAW/ISO/셔터 속도/EV 예시 값과 미구현 버튼은 표시하지 않는다. 시스템 폰트를 유지하고 숫자에만 시스템 고정폭 폰트를 사용한다. 버튼은 48px 이상, 작은 화면과 확대 글자는 스크롤로 접근하도록 작성했으며 실제 접근성·화면 검증은 NOT_RUN이다.

## 8. 성공 판단

대표 3종이 같은 사진에서 분명히 다르게 보이고, 원본보다 저장하고 싶은 결과가 있어야 한다. 처음 쓰는 사용자가 컬렉션과 필터의 차이를 설명할 수 있어야 한다. '한 장 세 분위기'가 선택을 돕는지도 별도로 확인한다.

초기 사용성 검수는 동의를 받은 10~15명의 소규모 테스트로 시작할 수 있다. 이 수치는 통계적 성공을 보장하는 표본 크기가 아니라 탐색적 검수 제안이다. MVP에 원격 추적을 자동 추가하지 말고 사용자의 직접 피드백으로 확인한다.
