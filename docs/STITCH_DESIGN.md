사용자가 다음 기능 대신 실제 필터 앱처럼 디자인하고 텍스트 조작을 아이콘으로 정리하도록 요청했다. 기존 Stitch 프로젝트 `7812018568704993424`의 카메라 화면 `6882efed6e4a40ba8cb3d0e9e99948ff`를 get_screen/download_file로 다시 열어 실제 시안을 확인했다. 원격 시안은 수정하지 않았다. 아래 과거 화면 배치보다 이 절이 우선한다.

### 디자인 결정

- 역할: 사진을 크게 보고 색감을 고른 뒤 촬영. 캔버스 #171717, 패널 #242424, 조절 배경 #1F1F1F, 본문 #F4F1EA, 보조 #BDB8B0, 선택 #E7CFAE를 기존 시안에서 이어 쓴다. 컬렉션 고유 색도 유지한다.
- 로고는 작은 `yeoun.` 워드마크(시스템 23/600), 동작/필터명은 한글 시스템 14~15, 수치는 Menlo/monospace 12~26. 로고 점은 선택한 필터의 색이다. 외부 폰트/새 의존성 없음.
- 특징: 가로 필터 카드에 같은 추상 풍경 구조와 서로 다른 팔레트/아이콘을 적용한다. 이는 식별용 아트워크이며 실제 LUT 처리 사진 썸네일이 아니다. 가짜 미리보기나 사진 전송 없이 필터를 구분한다. 선택은 테두리·체크·accessibility checked로 함께 표시한다.
- 처음 검토한 ‘텍스트 탭 + 필터 이름 + 조절 버튼’ 중복 구조를 없애고 8개 원본/필터를 직접 고르게 했다. 도시 2종도 메인에서 바로 접근한다. 같은 항목 재탭으로 설정을 초기화하지 않는다.

### 구현과 보존한 동작

- `CameraIcon`: 24pt 선·도형 기반 자체 아이콘. RN View만 사용하며 아이콘 폰트 로딩/추가 Canvas/네이티브 변경 없음. 장식 자식은 접근성 탐색에서 숨기고 버튼에 한국어 label/hint/state를 둔다. 기본 터치 영역48pt, 셔터80pt. 기존 단순 문자 화살표/기호를 대체했다.
- 메인: 상단 플래시는 off→auto→on→off로 직접 순환하고 auto는 A, 비지원은 비활성이다. 격자는 기본 꺼짐/아이콘 토글이다. 촬영 설정은 톱니바퀴, 필터 조절은 슬라이더로 구분한다. 실제 촬영/초점/비교 상태 제한과 3:4 실측 프레임 유지. 로딩 안내는 프레임 내부, 상태 높이는 예약하여 선택 중 프레임을 밀지 않는다.
- 패널: 상단 닫기 아이콘, 필터 스트립, 가로 효과 아이콘, 선택한 효과 하나의 계기/± 조절, 날짜 Switch·초기화. 기존 10% 단위와 스크린리더 increment/decrement를 유지하며 드래그 슬라이더라고 표시하지 않는다. 모든 기존 효과와 날짜에 접근 가능하다.
- 촬영 설정: 격자 Switch, 플래시 세그먼트, 중앙 초점, 노출 ±/초기화로 구분한다. 실제 노출 readback과 지원 여부는 기존 로직 그대로다. 개발 진단은 개발 전용으로만 남긴다.
- 결과: 상단 뒤로/편집 취소, 큰 사진과 필터명, 비교/색감 편집, 하단 고정 저장 액션. 파일 정보와 중복 안내를 축소했다. 편집 진입은 편집 영역으로 스크롤, 적용/취소는 사진으로 복귀한다. 저장 성공은 controller saved만 사용하고 저장 실패/권한/재시도·미저장 이탈 확인·중복 작업 잠금은 유지한다. 저장 후에는 ‘다음 순간 촬영’으로 전환한다.
- 비교: 누르기 동작과 유지 핀을 모두 제공한다. 원본 비교는 사진 설정이나 저장 결과를 바꾸지 않는다는 안내, 활성 상태·실패/준비 안내를 보존한다.

## 2026-10-29 필터 전환 중 프레임 크기 유지

로딩/오류 안내의 출몰이 flex 가용 높이를 바꾸던 문제를 수정했다. 필터 안내는 3:4 프레임 안에 absolute overlay로 배치하고, 오류 복구 버튼은 최소 48px 터치 영역으로 유지한다. 필터 선택 이름은 한 줄로 유지하며 전체 이름/설명은 접근성 label과 펼친 패널에서 확인한다. 원본과 필터 사이에 수치 표시가 바뀌어도 줄을 늘리지 않는다. 촬영 상태는 fontScale에 대응한 두 줄 높이를 항상 예약한다. 정상 필터 전환에서 카메라 영역을 밀어내는 로딩 줄은 없다. 기기 버튼 조작 및 모든 큰 글자 조합의 확인 상태는 PROGRESS를 따른다.

## 2026-10-29 실기기 피드백에 따른 촬영 화면 재배치

사용자는 아이폰에서 “여운 제목과 작은 카메라, 많은 조절 버튼”이 보여 디자인이 적용되지 않았다고 피드백했다. 이전 적용은 색상/일부 요소를 가져왔지만, 미리보기 폭을 `height - 400`으로 줄이고 후속 조작을 계속 세로로 추가해 원본 시안의 화면 위계를 잃었다. 캐시나 다른 앱 진입 문제가 아니라 최신 코드의 레이아웃 문제였다.

- Stitch 세 화면을 `list_screens` / `download_file`로 다시 열어 대조했다. 인증이 필요한 downloadUrl 직접 요청은 401이었고 공식 다운로드 도구로 읽었다.
- 상단은 YEOWUN 로고와 플래시/설정 진입으로 축소했다. 미리보기는 실측한 가용 영역에 3:4로 맞추고 고정 높이 공제를 제거했다. 탭 초점 좌표도 실제 프레임 폭을 계속 사용한다.
- 하단에는 컬렉션 탭과 선택 필터/강도만 두고 셔터·원본 비교·카메라 전환은 스크롤 밖에 고정했다. 셔터를 원본 시안의 둥근 사각형으로 맞췄다.
- 촬영 설정(격자/플래시/중앙 초점/노출/진단)과 필터 조절(선택/강도/입자/번짐/비교)을 스크롤 가능한 바텀 패널로 옮겼다. 패널은 카메라 소유권/활성 상태를 바꾸지 않고 뒤 화면의 접근성 탐색을 숨긴다. 패널 닫기에는 누르기 비교를 해제하며 고정 비교는 하단 버튼으로 복귀한다.
- 정상 화면의 상세 설명을 패널로 옮기고, 필터 오류는 한 줄 해결 진입과 패널 안 재시도로 표시한다. 실제 실패는 숨기지 않으며 셔터 잠금도 유지한다.
- 여전히 원본+대표 3종만 제공한다. 미구현 썸네일/가져오기/빛 가이드/RAW/ISO/공유/레시피 저장 버튼은 만들지 않았다. 결과 화면은 이번 수정 범위에 포함하지 않았다.

● 오후 네 시  80%                           조절 +

처음에는 시안처럼 큰 전체 폭 프레임을 고려했지만, 작은 기기에서 셔터가 화면 아래로 밀리는 점 때문에 높이에 맞춰 **3:4를 유지하며 프레임 폭을 줄이는 중앙 배치**로 정리했다. 작은 화면, 오류 안내, 강도 패널, 큰 글자는 세로 스크롤로 접근한다. 컬렉션 줄은 가로 스크롤을 허용한다. 화면 크기 대응은 코드에 작성했으며 렌더링으로 확인한 결과가 아니다.

## 디자인 적용 당시 기능에 맞춘 조정

- 원본 + 대표 LUT 3종만 연결한다. 빛/시간/장면 탭은 각 대표 필터를 선택하며 기본 강도 80%를 유지한다.
- 현재는 실제 엔진으로 만든 공통 썸네일이 없으므로 시안의 사진 썸네일 목록을 넣지 않는다. Stitch 샘플 사진을 카메라·필터 결과로 표시하거나 앱에 번들링하지 않는다.
- 강도 조절은 기존 10% 단위를 유지한다. 스크린 리더 조절 동작과 명시적인 두 버튼을 함께 제공한다. 입자·번짐·연속 슬라이더 구현으로 보고하지 않는다.
- 원형 셔터는 72px, 바깥 링은 84px다. 일반 동작은 최소 48px 터치 영역과 비활성/눌림 피드백을 사용한다. 전환·필터 선택에 스크린 리더 이름을 붙이고 선택 상태를 밑줄/선택 속성으로도 표시한다.
- 결과 화면은 실제 출력 파일의 크기 비율을 유지한다. 저장 성공은 기존 controller의 `saved`일 때만 표시한다. 실패 시 재시도, 저장 권한 설정, 미저장 이탈 확인을 연결한다. 임시 사진 정리 중 중복 저장/복귀 요청을 막는다.
- 결과 화면이 열린 동안 기존 CameraPreview를 유지한 채 비활성화한다. 복귀 시 필터 request revision과 준비 상태를 갱신한다. 픽셀/렌더러/촬영 snapshot 계약은 변경하지 않는다.
- 최초 디자인 작업에서 미구현 RAW, ISO/셔터/EV 표시, 플래시, 빛 가이드, 가져오기, 즐겨찾기, 공유, 원본 비교, 세 분위기, 오늘의 색 저장 버튼은 노출하지 않았다.
- 후속 카메라 원본 비교에는 기존 차콜/경계선 토큰으로 48px 이상 누르기 버튼과 유지 스위치를 추가했다. 비교/전환 중을 텍스트로 구분하며 큰 글자에서는 줄바꿈한다. 선택한 필터 패널은 유지하고 미리보기만 바꾼다. 결과 사진 비교는 미구현이며 원격 Stitch 파일은 수정하지 않았다. 화면·제스처·접근성 실행 확인은 NOT_RUN이다.
- 후속 격자·플래시에는 프레임 위 조작 영역에 격자 switch와 off/auto/on radio를 추가했다. 선택 경계선과 checked 상태, 미지원 안내를 제공하며 작은 화면에서 줄바꿈한다. 격자는 실제 프레임 안의 1/3·2/3 지점에 얇은 선 4개로 표시하고 터치를 받지 않는다. 기존 모서리 표식은 유지한다. 저장 이미지, 원격 Stitch 시안, 폰트/색상 토큰은 바꾸지 않았으며 실제 화면·접근성은 NOT_RUN이다.
- 초점·노출 후속 작업은 프레임의 탭 위치 표식과 별도 중앙 초점, 노출 −/＋/기본 밝기 조작을 추가했다. 기존 차콜/컬렉션 light 토큰과 48px 터치 영역을 사용하며, native readback 전 숫자를 성공값으로 표시하지 않는다. iOS는 EV, Android는 설치 구현에 맞춘 보정 단계다. 시안의 예시 ISO/셔터 속도는 추가하지 않았다. 초점 표식은 저장 JPEG에 포함되지 않는다. 화면/접근성/실제 초점 검증은 NOT_RUN이다.
- 개발 진단은 기존 개발 전용 경로를 유지한다. 화면 진입만으로 합성 검사를 실행하지 않는다.
