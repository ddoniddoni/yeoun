```text
여운 ·                           오늘의 빛, 나의 색
PHOTO                                     3:4 · 후면
           ┌─────────────────────────┐
           │   실제 3:4 카메라 프레임  │
           └─────────────────────────┘
원본     빛     시간     장면
● 오후 네 시  80%                           조절 +
따뜻한 빛, 맑은 그림자
[펼친 경우: 강도 표시 / −10% / +10%]
색감 초안              ○ 셔터                  전환
```

처음에는 시안처럼 큰 전체 폭 프레임을 고려했지만, 작은 기기에서 셔터가 화면 아래로 밀리는 점 때문에 높이에 맞춰 **3:4를 유지하며 프레임 폭을 줄이는 중앙 배치**로 정리했다. 작은 화면, 오류 안내, 강도 패널, 큰 글자는 세로 스크롤로 접근한다. 컬렉션 줄은 가로 스크롤을 허용한다. 화면 크기 대응은 코드에 작성했으며 렌더링으로 확인한 결과가 아니다.

타이포그래피는 한글 시스템 폰트를 중심으로 25px 로고/22px 필터명/15px 동작/13px 설명을 사용한다. 숫자에는 iOS Menlo, Android monospace를 쓴다. Stitch의 웹 폰트는 다운로드하지 않는다. 네 모서리 선은 프레임 경계만 나타내며 자동 초점·수평계 동작으로 보이는 중앙 표식은 제외했다. 선택한 컬렉션의 작은 점과 밑줄이 화면의 고유 요소다. 네온·블러·그라디언트·가짜 촬영 정보를 추가하지 않는다.

## 현재 기능에 맞춘 조정

- 원본 + 대표 LUT 3종만 연결한다. 빛/시간/장면 탭은 각 대표 필터를 선택하며 기본 강도 80%를 유지한다.
- 현재는 실제 엔진으로 만든 공통 썸네일이 없으므로 시안의 사진 썸네일 목록을 넣지 않는다. Stitch 샘플 사진을 카메라·필터 결과로 표시하거나 앱에 번들링하지 않는다.
- 강도 조절은 기존 10% 단위를 유지한다. 스크린 리더 조절 동작과 명시적인 두 버튼을 함께 제공한다. 입자·번짐·연속 슬라이더 구현으로 보고하지 않는다.
- 원형 셔터는 72px, 바깥 링은 84px다. 일반 동작은 최소 48px 터치 영역과 비활성/눌림 피드백을 사용한다. 전환·필터 선택에 스크린 리더 이름을 붙이고 선택 상태를 밑줄/선택 속성으로도 표시한다.
- 결과 화면은 실제 출력 파일의 크기 비율을 유지한다. 저장 성공은 기존 controller의 `saved`일 때만 표시한다. 실패 시 재시도, 저장 권한 설정, 미저장 이탈 확인을 연결한다. 임시 사진 정리 중 중복 저장/복귀 요청을 막는다.
- 결과 화면이 열린 동안 기존 CameraPreview를 유지한 채 비활성화한다. 복귀 시 필터 request revision과 준비 상태를 갱신한다. 픽셀/렌더러/촬영 snapshot 계약은 변경하지 않는다.
- 미구현 RAW, ISO/셔터/EV 표시, 플래시, 빛 가이드, 가져오기, 즐겨찾기, 공유, 원본 비교, 세 분위기, 오늘의 색 저장 버튼은 노출하지 않는다.
- 개발 진단은 기존 개발 전용 경로를 유지한다. 화면 진입만으로 합성 검사를 실행하지 않는다.

## 확인 범위

Stitch 스크린샷과 디자인 시스템, 저장소 diff, 설치된 RN 0.83.10의 Pressable/Modal 타입을 읽었다. [Pressable](https://reactnative.dev/docs/0.83/pressable), [Modal](https://reactnative.dev/docs/0.83/modal), [useWindowDimensions](https://reactnative.dev/docs/0.83/usewindowdimensions) 공식 문서와 대조했다.

**테스트·lint·typecheck·react-doctor·번들·네이티브 빌드·앱 실행·스크린샷 검증은 NOT_RUN**이다. 사용자가 실행을 요청하기 전까지 자동 실행하지 않는다. 디자인 원본을 본 것과 앱이 그 디자인대로 렌더링되는 것을 확인한 것은 다르다. G0/G1은 계속 NOT_PASSED다.

사용자 요청 후 iPhone/Android에서 작은 화면, 글자 확대, VoiceOver/TalkBack, 권한 거부, 필터 로딩/실패, 전면 방향, 결과 화면 왕복, 저장 실패/재시도, 저장 중 뒤로가기 차단, 미저장 이탈 취소, 갤러리 저장 뒤 다음 촬영, 앱 복귀를 확인한다.
