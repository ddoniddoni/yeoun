# 여운 필터 그림

밝은 인화지 위에 필터마다 하나의 사물을 그린 식별용 아트워크다. 실제 LUT를 적용한 사진 썸네일이 아니다. 그림은 이번 작업에서 직접 작성했으며 외부 사진·아이콘 세트·폰트·생성형 이미지 서비스를 사용하지 않는다.

- 원본: `artwork.mjs`의64×64 벡터 도형. 공통2unit 선, 둥근 선 끝, 진한 갈색 잉크와 제한된 사물 색을 사용한다.
- 앱:192×192 PNG18개를 React Native Image로44pt에 표시한다. 모든 PNG는 흰 배경이며 카드도 흰색을 유지한다. SVG/렌더 스크립트는 앱에서 불러오지 않는다.
- 생성: macOS에서 `node scripts/generate-filter-icons.mjs`. 시스템 Quick Look으로 PNG를 내보내며 패키지를 설치하지 않는다. 중간 SVG와 검토용 전체 그림판은 ignored `work/filter-icon-artwork/`에 생성한다. 다른 플랫폼에서는 커밋된 PNG를 그대로 사용한다.
- 변경 후 전체 그림판과 실제 카드 크기에서 선/여백/체크·즐겨찾기 표시의 겹침을 확인한다. 이 자산은 필터 계산이나 사진 저장 경로에 들어가지 않는다.
